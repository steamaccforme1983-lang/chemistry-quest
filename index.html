Earn 20 XP the first time you answer each question correctly. Every 6th consecutive correct answer earns 24 XP (20% extra) if that question hasn’t already awarded XP. Repeated correct answers award no extra XP. Every 100 current XP brings a level.

Every 5 consecutive wrong answers halve your current XP, rounded down to a whole number. Another 5 wrong in the same streak halve it again. A correct answer resets the wrong streak; a wrong answer resets the correct streak. Levels can decrease when XP is lost. Cancelling a confirmation or skipping a question changes neither streak.
